# Preview lower access

Open your avatar menu and use **Explore with lower access**. Choose Guest, Member, or an administrator level you currently hold, then Apply preview. A banner identifies the selected level; **Restore my access** exits immediately.

Preview is read-only: saving, uploading, deleting, approving and other POST actions are rejected on the server. Guest preview uses Global-only browsing. Private and Server entries still require normal signed-in access. Your account, Discord roles and saved content are unchanged. Selecting Server administrator does not include Global administrator privileges, and vice versa.

Current permissions are checked again on each request. If a selected grant has been removed, the preview falls back to Member. Role-based Server administrators are supported. No environment variables or database migrations are required.
