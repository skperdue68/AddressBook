# Pending submissions: administrative review only

Pending houses are excluded from normal web and Discord discovery, personal lists, tour stops, management screens, gallery access and Share Pass viewing. Submitters and administrators use the authorized approval queue to review them; normal editing does not bypass approval.

Registration, visibility changes and Share Pass copies that require approval show a generic submission acknowledgement instead of redirecting to an inaccessible house page. Approval and rejection remain in Administration. Existing statuses and records are preserved; no database migration or production data changes are required.

Verification covers submitter and administrator access, personal collections, tour stops, gallery authorization, administrative review and pending-copy redirects, followed by the full existing suite.
