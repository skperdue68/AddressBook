# House discovery and sharing polish — 2026-10-28

This change improves house lists, statistics, personal actions and shared-record management on the web and Discord.

- House lists and discovery cards show the existing gallery cover beside the name when available. Ordinary Active status is hidden; Pending remains visible. Featured cards continue to show gallery covers.
- Statistics counts are equal-size centered links, sized for the longest visible number. The two server rankings align by row on wide screens and stack naturally on small screens.
- Discord house cards put Share House next to Add to a Tour, retain Favorite and Comments, and group edit, visibility and delete under Manage House. Comments refresh their count on return. Management retains the originating list, expanded state and navigation; deletion returns to the list. Pending records remain manageable by authorized editors.
- Want to Visit and Visited controls are removed from both interfaces. Existing saved state is retained for compatibility; it is not erased by this update. Favorites remain reversible. Tour progress is separate and remains available.
- Gallery editors can move each screenshot earlier or later. The first image is the cover. Moves recheck edit access and only reorder images within that registration.
- Sharing offers the last successfully posted channel or thread for the same Discord user and server, across house and tour Share Passes and across web/Discord. It uses existing pass history, so it survives restarts without a new migration. Stale or inaccessible destinations are omitted, and explicit confirmation and fresh posting permissions are still required. Shares whose message metadata could not be saved cannot supply a remembered destination.
- House details identify the Discord submitter separately from the ESO owner. Shared house/tour reassignment has a live server-member list and name search, with an ID/mention fallback. The source server and current membership are checked; Private records remain excluded from administrative reassignment.
- Clickable tag badges retain their search links and keyboard focus outline without hyperlink underlines.
- The readable guide and downloadable Word guide describe the updated controls.

## Deploy

Merge this PR into master, then run from the existing Linux checkout:

```bash
git pull --ff-only
npm ci
sudo systemctl restart hearthbound
sudo journalctl -u hearthbound -n 50 --no-pager -l
```

No new database schema migration is introduced. Gallery support from the earlier upgrade requires its existing schema and persistent HOUSE_IMAGE_DIR. Run npm ci when deploying changed dependencies; the gallery uses sharp.

Discord member searches depend on Discord permitting member-list/search requests. When unavailable, the screen explains this and keeps the ID/mention workflow, whose current-member validation still applies.
