Capacity badges now visibly say “6 max”, “12 max” or “24 max” alongside the solid people icon. Existing maximum-capacity tooltip/accessible labels remain, and unavailable limits are still omitted. Shared Discord capacity text also says “max”. No visitor counters or catalog limits changed.

Agony’s Ascent (official house 93) was checked on 2026-10-29. The renderer uses the stored zone and style independently; it does not substitute the zone for a missing style. Existing data records The Deadlands for both. ESO-Hub’s own house catalog lists Deadlands as both Location and Style: https://eso-hub.com/en/houses/agonys-ascent . This supports the repeated labels, so no catalog or production database rewrite is warranted. UESP’s direct page was unavailable to the browsing tool (403) during this check.
