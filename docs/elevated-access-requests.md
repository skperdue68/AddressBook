# Request Elevated Access

The profile menu offers **Request Elevated Access** only when another administrator access type can be requested. Existing access and pending requests are excluded. Server access applies to the selected connected Discord server; Global access applies to the selected ESO platform and region. Personal web workspaces can request Global access without installing the bot.

When only one access type is available, its request opens directly. With both types available, the web shows equally sized request cards and Discord uses a single choice menu. Requests still require approval. Private houses and tours remain creator-only.

Discord Support keeps first-server administrator setup and Global request review separate from access requests. Existing reviewers retain their approval tools. A lower-access web preview uses actual grants when deciding whether more access is available and remains read-only.

No database migration or environment changes are required.
