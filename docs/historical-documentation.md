# HearthBound historical documentation

HearthBound was previously named AddressBook. Versioned AddressBook current-state files, operations plans, installation notes and engineering specifications in this repository are retained as historical records. Their original names, commands, paths and feature descriptions can differ from the current release; do not use them as current deployment instructions.

For current instructions use the [member guide](member-guide.md), [administration guide](administration.md), [current feature reference](HearthBound-current-state.md), [production upgrade guide](upgrade-v1.0.62.md), and [HearthBound Word user and administrator guide](../HearthBound_User_Admin_Guide.docx).

The old per-release installation notes (`INSTALL.txt` and `INSTALL-v1.0.59.txt` through `INSTALL-v1.0.61.txt`) used to sit in the repository root. They now live in [`historical/`](historical/) and describe long-superseded AddressBook releases; use the current guides above instead.
